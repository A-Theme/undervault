Lanterns of the Undervault · dernière mise à jour le 16 novembre 2026

En bref : le jeu garde vos héros sur votre appareil. Si vous utilisez les fonctions en ligne, le peu dont elles ont besoin va au serveur du jeu. Si vous vous connectez, votre compte et vos sauvegardes y vont aussi, pour que vous puissiez jouer sur n'importe quel appareil. Il n'y a ni publicité, ni pistage, ni statistiques d'audience, et rien n'est vendu ni partagé à des fins commerciales. Vous pouvez supprimer votre compte et tout ce qu'il contient depuis le jeu.

Sur votre appareil

Vos héros, vos réglages, votre liste d'amis et votre code ami sont enregistrés dans le stockage de votre navigateur (ou de l'appli) sur votre propre appareil. Ils y restent, sauf si vous utilisez les fonctions ci-dessous.

Le microphone

Une page du jeu vous demande de dire quelque chose à voix haute. Le jeu n'utilise le microphone qu'après que vous avez touché Parler sur cette page, et seulement quelques secondes. Ce que vous dites est comparé aux propres enregistrements du jeu, sur votre appareil. Rien de ce que vous dites n'est enregistré, conservé ni envoyé où que ce soit. L'application demande l'autorisation la première fois ; vous pouvez refuser, et le reste du jeu fonctionne de la même façon.

Les fonctions en ligne

Elles utilisent une base de données et un serveur en temps réel hébergés sur Supabase pour ce jeu. Chacune n'envoie que ce dont elle a besoin :

  • Classements et courses de graines (activés sauf si vous désactivez « Envoyer les scores » dans le menu) : le nom de votre héros, sa classe, son niveau, sa progression (étage atteint, boss, morts, fin), la graine et un identifiant aléatoire pour la partie. Ces données sont publiques : n'importe quel joueur peut voir les classements.
  • Jeu en direct et raids (seulement quand vous les activez) : le nom de votre héros, sa classe, son niveau, votre position dans le donjon et ce que vous dites dans le chat, partagés en direct avec les autres joueurs sur la même graine ou dans votre groupe. Rien n'est conservé après votre départ.
  • Chat de la Salle commune (seulement après avoir accepté les règles du chat, et seulement tant que le chat est activé) : votre nom de joueur, votre code ami et ce que vous écrivez dans le salon, envoyés aux joueurs en ligne et conservés sur le serveur du jeu pendant 24 heures, pour que ceux qui se connectent plus tard puissent lire ce qu'ils ont manqué. Au bout de 24 heures, tout est supprimé définitivement.
  • Messages à un seul joueur : envoyés en direct quand il est en ligne. Quand il est hors ligne, un message n'est conservé pour lui que si vous avez tous deux ouvert une session ; seuls vous deux pouvez le lire, et il est supprimé au bout de 24 heures.
  • Signalements : si quelqu'un vous signale, votre code ami, votre nom et vos dernières lignes telles qu'il les a vues sont conservés pour que le signalement puisse être examiné.
  • Amis : votre code ami, votre nom de joueur, votre héros et l'endroit où vous êtes sont montrés aux joueurs présents dans le salon des amis pendant que vous êtes en ligne (désactivez-le avec « Me cacher » sur l'écran Amis). Les invitations et demandes d'ami ne vont qu'au joueur concerné.

Si vous vous connectez

La connexion est facultative. Vous vous connectez avec Google ou Discord, ou avec un code que le jeu vous envoie par e-mail ; le jeu ne voit ni ne garde jamais de mot de passe. Quand vous le faites :

  • Google ou Discord communique au serveur du jeu votre adresse e-mail, votre nom et l'adresse de votre photo de profil. Ils sont conservés avec votre compte, utilisés uniquement pour vous connecter, et jamais montrés aux autres joueurs.
  • Si vous vous connectez par e-mail, le serveur du jeu conserve votre adresse e-mail et y envoie le code via un service d'envoi d'e-mails. L'adresse sert uniquement à vous connecter, et n'est jamais montrée aux autres joueurs.
  • Votre profil est conservé : votre nom de joueur, votre code ami et votre liste d'amis, pour qu'ils vous suivent sur chaque appareil.
  • Vos héros sont conservés comme sauvegardes dans le nuage (les héros Hardcore restent sur leur propre appareil), pour que vous puissiez continuer depuis un autre appareil.
  • Les scores envoyés pendant que votre session est ouverte affichent votre nom de joueur dans les classements publics.

Personne d'autre que vous ne peut lire ou modifier votre profil et vos sauvegardes ; la base de données l'impose.

Acheter le jeu complet

Le Livre I est gratuit. Si vous achetez le jeu complet :

  • Sur le site, Stripe encaisse le paiement en tant que vendeur officiel, via son paiement Link. Vos coordonnées bancaires, votre adresse de facturation et votre e-mail vont chez eux, jamais au jeu. Le serveur du jeu enregistre seulement que votre compte possède le jeu complet, avec le numéro de paiement de Stripe, pour qu'il se débloque partout où vous vous connectez.
  • Dans l'appli Android, Google Play encaisse le paiement et conserve l'achat avec votre compte Google. L'appli demande seulement à Google Play si vous possédez le jeu complet ; rien concernant l'achat ne va au serveur du jeu.

Supprimer vos données

  • Tout : dans le jeu, ouvrez le menu, puis Compte, puis Supprimer mon compte. Cela supprime votre compte, votre profil, chaque sauvegarde dans le nuage, ceux de vos messages de chat encore dans leurs 24 heures, et la trace d'un achat sur le site, d'un coup et pour de bon. Les héros enregistrés sur vos appareils y restent jusqu'à ce que vous les supprimiez.
  • Un seul héros : supprimez-le sur l'écran d'accueil ; avec une session ouverte, cela supprime aussi sa sauvegarde dans le nuage.
  • Les scores déjà présents dans les classements publics ne sont pas liés à votre compte et ne sont pas supprimés avec lui ; pour en faire retirer un, ouvrez un ticket sur github.com/A-Theme/undervault/issues.

Qui d'autre intervient

  • Supabase fait fonctionner la base de données, la connexion et le serveur en temps réel.
  • Google et Discord, si vous vous connectez avec eux.
  • Stripe (et son paiement Link) et Google Play, si vous achetez le jeu complet.
  • GitHub Pages héberge le site du jeu, et le jeu charge ses polices depuis Google Fonts. Comme tout hébergeur, ils voient votre adresse IP quand vous chargez la page.

Enfants

Le jeu ne collecte pas sciemment d'informations personnelles auprès d'enfants de moins de 13 ans. La connexion nécessite un compte Google ou Discord, qui ont leurs propres règles d'âge.

Modifications et questions

Si cela change, la date en haut change aussi. Questions : écrivez à support@playundervault.com .
