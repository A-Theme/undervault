The browser would not open the microphone on this page. Browsers only allow the mic on HTTPS or localhost (Chrome and Edge also block it on file://). On a computer, in the repo folder run node say-it-back/serve.js and open http://127.0.0.1:8765/recorder.html. ILVAREN OSSA VEN

ill-VAH-ren · OSS-ah · ven

“Ilvaren, be kept.”

How to say it, and the four good takes
WordSay itNotes
ILVARENill-VAH-ren“ill” as in ill, VAH as in father, “ren” as in wren. Three syllables, not “il-VAIR-en”.
OSSAOSS-ah“oss” as in moss, then a soft “ah”. Stress on the first part.
VENvenas in seven, said plainly. Don’t drop it.

Read it plainly, the way a careful person reads three strange words aloud: clear, at an easy pace, no whisper, no chant. A brief breath between the words is fine; don’t leave a long pause. The line is about two to three seconds.

Each voice: (1) an easy, normal pace, (2) a little slower and more careful, (3) a little quicker, as if you know it well, (4) a little quieter, as if reading it to yourself. Aim for three or four voices.

Ready. Type a name, then record.

On a phone, tap Record to start and stop. On a computer, Space does the same, unless you are typing a name; you can also press and hold Record. Takes stay in this page until you download them; a refresh clears the list.

Takes

    After you record

    Each file is a 16 kHz mono 16-bit PCM WAV, named good/ilvaren-<who>-<n>.wav (or wrong/<name>.wav). Put the folders in say-it-back/, then from the repo root:

    node tools/spell-prints.js say-it-back/good --wrong say-it-back/wrong --dry

    If the report looks right, run it again without --dry to write the fingerprints into src/secrets.js, then npm run build && npm test. The recordings themselves stay out of the repo. Full notes are in SAY-IT-BACK-RECORDING.md.
